SQL Security Judge Policy

  • Allowed: SELECT, WITH, aggregations, joins, subqueries
  • Blocked: INSERT, UPDATE, DELETE, DROP
  • Blocked: ALTER, TRUNCATE, CREATE, GRANT, REVOKE
  • Execution: Transactions auto-rollback on non-select triggers
