SQL Security Judge Policy

  • Allowed: SELECT, WITH, aggregations, cross-table joins
  • Blocked: INSERT, UPDATE, DELETE, DROP
  • Blocked: ALTER, TRUNCATE, CREATE, GRANT, REVOKE
  • Execution: Read-only transactions with rollback guard
